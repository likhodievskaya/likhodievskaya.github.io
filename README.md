# Сайт: как начать

## Что в папке

- `public/`: сам сайт, именно эта папка публикуется
  - `index.html`: страница
  - `styles.css`, `script.js`: стили и анимация точек
  - `img/`: обработанные фото, `fonts/`: шрифты сайта
  - `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`: значок сайта
  - `og-image.png`: картинка для превью ссылок в мессенджерах
- `materials/`: презентации программ и записи экрана. На сайт не попадают
- `CLAUDE.md`: все решения по сайту для Claude Code. На сайт не попадает

## Посмотреть сайт у себя

Откройте `public/index.html` двойным кликом, он откроется в браузере.

## Работа в Claude Code

Откройте эту папку в Claude Code и начните, например, так: «Прочитай CLAUDE.md и давай продолжим работу над сайтом».

## Публикация

Сайт опубликован: https://likhodievskaya.github.io

Он лежит на GitHub Pages в репозитории `likhodievskaya/likhodievskaya.github.io`. После любой правки в папке `public` достаточно сохранить изменения в git и отправить их на GitHub (`git push`): сайт обновится сам за 1-2 минуты.
